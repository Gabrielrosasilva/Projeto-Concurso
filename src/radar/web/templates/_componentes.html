{# Os componentes do design system, como macros. O estilo mora em /estatico/design.css; aqui mora o MARKUP, para toda tela escrever o mesmo selo do mesmo jeito. Use assim: {% from "_componentes.html" import selo, legenda_dos_selos %} {{ selo(linha.origem) }} {{ selo('ia', 'Macete (IA)') }} Os selos moram no radar/origem.py (o SELOS, global do Jinja): as quatro origens do novo.md, tres variacoes com uma palavra a mais (prova, classificacao, tendencia) e o plano. O servico grava a origem no dado e a tela passa a origem adiante - quem escolhe a cor e o dado. `texto` troca so a palavra; a cor e o emoji ficam, porque sao eles que dizem a origem. #} {% macro selo(tipo, texto=None, curto=False) -%} {%- set s = SELOS[tipo] -%} {%- if curto -%} {{ s.emoji }} {%- else -%} {{ s.emoji }} {{ texto or s.texto }} {%- endif -%} {%- endmacro %} {# A origem de um selo, que e a familia de cor do bloco que o acompanha. #} {% macro familia(tipo) -%}{{ SELOS[tipo].origem }}{%- endmacro %} {# Sem `tipos`, todos os selos que alguma tela usa, na ordem do origem.py. #} {% macro legenda_dos_selos(tipos=None) %}
{% for t in (tipos or SELOS) %}{{ selo(t) }}{% endfor %}
{% endmacro %} {# Um bloco dentro do cartao, na cor do selo. Tudo que esta dentro dele tem aquela origem - e so aquela. #} {% macro bloco(tipo, titulo) %}
